## Two things the council proved wrong

**We are not iteration-limited.** I had argued that a 60M run reaching 390,110
of the tree's 3,438,484 positions meant the solver was starved and a bigger tree
would starve it further. The counts say otherwise:

| rung | entries | iterations |
|---|---|---|
| cap2_70bb_t421_20m_warm | 389,086 | 20.1M |
| cap2_70bb_t421_60m_warm | 390,110 | 60.1M |
| hist20_70bb_t421_20m | 1,163,595 | 20M |
| hist20_70bb_t421_60m | 1,170,732 | 60.1M |

Three times the work finds 0.26% more nodes. The reachable tree is about 390,000
positions and 20M saturates it; the other three million are unreachable or so
rare they are never sampled. What the extra iterations buy is not coverage but
strategy quality at nodes that already exist, which is a different claim and also
true: lane IT's 60M retrain removed the 98% pocket jacks shove that the same
rung's 20M solve had left in, and the sweep can see that although the node count
barely moved.

The consequence is the useful part. **20M is enough to decide an experiment, 60M
is the floor for a set that plays.** A tree experiment that looked like 5h19m is
2,201 seconds, so the question that has been hanging over the ladder for two days
can be answered this afternoon.

**A jam-only raise level is not free.** I said a level that holds only all-in
adds nothing, on the evidence that (4,2,1,1) counts the same as (4,2,1). That is
true only for a level sitting behind another jam-only level, which is
unreachable. The third level in (4,2,1) sits behind a level that still has a
sized raise in it:

```
(4,2)     1,287,154 positions
(4,2,1)   3,438,484 positions      the jam-only third level costs 2,151,330
```

Sixty-three percent of the tapered tree is a level whose only move is to shove.

**And the exploiter is better than I reported.** v5x's calibrated panel row is
66.5 / 66.6 / 67.0 / 65.2 / 64.5 (station, nit, maniac, fold-or-raise, hoops),
not the 64.4 / 64.3 / 65.6 / 59.1 / 60.2 I had quoted, which belongs to BR2. It
is six to ten points above v5i on every shape.

## What the four seats concluded

**Reshape the tree.** The three-bet node is reached 2,252 times in the 26,664
logged decisions, and there we raise 8.8% where heads-up theory is roughly twice
that, because a tapered rung's only re-raises are 10bb and a jam. These cost the
same to the position: (4,2,1), (4,3) and (3,3,1) are all 3,438,484. Restoring the
pot-sized three-bet is free if the schedule is allowed to name its sizes rather
than count them from the largest end.

**Train, do not rewrite.** Conceded the split above, withdrew its competing claim
on the burst slot, and found a test that costs no training at all: v5h carries
20M histogram rungs everywhere, and the 60M deep rungs already exist, so a ladder
of v5h with those three swapped in isolates iterations exactly. A duel answers in
minutes what would otherwise take a day.

**Exploit the field.** Moved its own gate from the burst to the replay, which
reads our logged record: real bots, real hands, no quota. The burst stays as
confirmation rather than proof, because this morning's queue served Blueprint 16
times out of 20 and 16 matches is about ±12 points. v5x's only fixture candidate
this season is PoetAndCoder on Friday, which folds 24% and calls 59% of the bets
it faces over 999. Never wsp, never pkr-sota.

**Freeze and gate.** Found that this morning's first dry run started at 10:50:14
while `chipzen/player.py` was written at 10:54:54, so the code that would have
connected tonight had never connected. Narrowed its own position afterwards: the
freeze binds the match path in the main working tree, not all engineering, and
experiments in a separate worktree with an isolated build are safe.

Fixed in advance, so the answer cannot be fitted afterwards:

1. More than +6 chips a hand at 70bb over 60,000 duplicate deals against v5i's
   tapered rung, which is two standard errors on that instrument.
2. Not worse than v5d's cap-2 rung, which is the honest control because it
   already holds the sizes.
3. Holds on a second seed.
4. Lifts the three-bet rate at the deep preflop node above about 12%, from the
   8.8% in the record.
5. Adds no new heavy-shove node to the strategy sweep.
6. Retrained at 60M and gated before a fixture, never at 20M.

Anything less and the reshape is a curiosity, and v5i closes the season.
